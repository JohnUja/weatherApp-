# 🌤️ WeatherStack

A sleek and dynamic weather app that lets you search real-time weather by city, create cards, and build a personal stack of favorite locations.

## 🔑 Features

- Search any city and get current weather data (temp, description, icon)
- Add/remove city cards from your custom stack
- Smart UI: nav arrows appear only when needed
- Clean card toggle with + and - buttons
- Responsive design with a modern look

## 🧠 Skills Applied

- JavaScript classes and DOM manipulation
- Dynamic UI logic and state handling
- REST API integration (OpenWeatherMap)
- Thoughtful UX decisions (conditional nav, stack behavior)
- Modular, scalable code (ready for backend integration)

## 🔧 Built With

- HTML, CSS, JavaScript (frontend)
- Node.js + Express (backend)
- OpenWeatherMap API (third party)
